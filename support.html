Support de Sabai en test

Mise à jour du 21 octobre 2026.

Support assuré par Julia Denat : juliadenat10@gmail.com.

Cette phase de test est réservée aux adultes de 18 ans ou plus invités individuellement. Ne partagez pas votre invitation TestFlight.

Le support technique n'est pas assuré en continu et aucun délai de résolution n'est garanti pendant cette phase. Les demandes concernant vos données suivent les délais précisés dans la notice de confidentialité.

Signaler un problème

Indiquez le modèle de votre iPhone, la version d'iOS, la version et le numéro du build Sabai, l'heure du problème et les étapes pour le reproduire. Pour un exercice, précisez la langue, le thème et les mots concernés.

Vous pouvez joindre une capture en masquant vos données personnelles. N'envoyez jamais votre mot de passe, un code Apple, une clé API ou des informations de carte bancaire.

Vous pouvez aussi envoyer un retour depuis TestFlight. Ce retour est traité par Apple et transmis à Julia selon les règles TestFlight. Évitez d'y inclure des données personnelles inutiles.

Le compte ne se confirme pas

Vérifiez les courriers indésirables et utilisez le dernier e-mail de confirmation reçu. Si aucun message n'arrive, contactez Julia en indiquant l'heure de l'essai. Ne transmettez ni code ni lien de connexion. L'envoi des e-mails de test peut nécessiter un réglage du service d'authentification, il ne suffit pas de répéter les inscriptions.

Premium ne se débloque pas

Vérifiez que l'app est installée depuis TestFlight et que vous êtes connectée au compte Sabai utilisé lors du test. Essayez la vérification de l'abonnement, puis la restauration avec le compte d'origine. Si l'état reste en attente, contactez le support sans acheter à nouveau.

Les achats TestFlight sont des tests sandbox. Pour modifier le renouvellement, utilisez Gérer l'abonnement et les réglages de test Apple. Supprimer Sabai ou son compte n'annule pas un abonnement.

Compte et données

Les réglages de Sabai permettent de demander la suppression du compte. Pour une demande d'accès ou d'effacement complémentaire, contactez le support depuis l'adresse liée à votre compte. Une vérification adaptée pourra être nécessaire. Les demandes concernant les données d'abonnement détenues par les prestataires nécessitent un traitement séparé.

Julia organise les demandes complémentaires auprès des prestataires. Les échanges de support et leurs pièces jointes sont supprimés de la boîte de support trois mois après résolution. Les copies internes de Google et les retours TestFlight suivent les cycles distincts indiqués dans la notice de confidentialité.

Microphone

Le microphone nécessite une version native et votre autorisation dans les réglages de l'iPhone. Expo Go ne permet pas de valider tout le parcours natif. Le mode oral actuel est un entraînement, pas un test certifié de prononciation.

Fin des tests

La campagne dure 90 jours à partir de la date d'ouverture indiquée dans votre invitation. Vous pouvez arrêter avant sa clôture. Les conditions des tests et la notice de confidentialité précisent les suites de cet arrêt et les délais de suppression.
